# Assets

Put personal files here:

| File | Purpose |
|------|---------|
| `hero.png` | Hero section architectural wireframe visual |
| `resume.pdf` | Linked from the contact section download button |
| `portrait.jpg` | Optional — replace the profile placeholder in `index.html` |

After adding a portrait, update the profile image block in `index.html` to use:

```html
<img src="./assets/portrait.jpg" alt="Portrait of Arun" class="w-full h-full object-cover grayscale hover:grayscale-0 transition-all duration-700" />
```
